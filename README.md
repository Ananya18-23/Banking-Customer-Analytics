# 🏦 Banking Customer Analytics

> **End-to-End Banking Customer Analytics using Python, MySQL & Power BI**

An end-to-end data analytics project focused on analyzing **banking customers, deposits, loans, accounts, customer demographics, and financial behavior** to generate meaningful business insights and build an interactive Power BI dashboard.

---

## 📌 Project Overview

The **Banking Customer Analytics** project analyzes customer-level banking data to understand:

* 👥 Customer demographics
* 💰 Deposits and savings
* 🏦 Loan distribution
* 💳 Credit card balances
* 📊 Checking and savings accounts
* 🌍 Customer nationality and occupation
* 📈 Customer financial behavior
* ⚠️ Risk-related customer characteristics

The project follows a complete analytics workflow:

**Raw Data → Python EDA → MySQL → Data Analysis → Power BI Dashboard → Business Insights**

---

## 🎯 Objectives

* Analyze the overall banking customer base.
* Understand customer financial behavior.
* Analyze loans and deposits across customers.
* Identify important customer segments.
* Explore relationships between demographics and financial products.
* Create an interactive dashboard for business decision-making.
* Transform raw banking data into actionable insights.
